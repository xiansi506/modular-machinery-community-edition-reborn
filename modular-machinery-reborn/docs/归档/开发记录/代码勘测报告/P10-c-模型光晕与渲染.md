## 通过的静态契约

- **世界隐藏索引（render/）**：`WorldVisibilityIndex` 用 volatile 不可变快照供地形工作线程无锁读（"Client-thread writes, immutable snapshots"；不引客户端/可选模组类型——coremod 钩子类在专用服务器也要可加载）；`replace` 做差异比较，只对变化的方块重建**含相邻 section**（遮挡面暴露）；"控制器占另一台机器 pattern 位"时组件集剔除 owner 位，**自定义渲染器永不隐藏**（models 与 components 分离）。钩子（`hiddenModel/hiddenComponent/hiddenNeighbor/hiddenBlockEntity`）都以 `view instanceof RenderView` + 世界身份匹配为准——预览世界天然排除。
- **隐藏触发链（WorldComponentHider）**：只有"真实客户端世界里实际画成功过的模型"才允许藏地形（`modelRendered(controller, success)`，预览世界直接 return）；控制器用 WeakReference 持有，失效/移除/换世界即清；定义变更、`ClientModelRegistry.generation()` 变更、结构快照变化都会把 `modelAvailable` 拉回 false（模型不可用的瞬间先恢复显示再隐藏——不闪空）；旧存档无 pattern 快照时用 `runtimeStructure` 重建到服务器首次检查为止。
- **Bloom 后处理（MachineBloom）**：PostChain 懒建 + 主渲染目标变更/窗口尺寸变化时重建；mask 临时目标 `copyDepthFrom` 进、`copyDepthFrom` 出（PostPass 清深度被复原）；投影/模型视/排序三态在 try 外保存、finally 恢复；异常与 LinkageError 一次失败即整体降级（"直到资源重载"）——渲染管线故障不会每帧刷日志；BufferBuilder 池有 64 纹理上限与"未完成批次丢弃"路径；登出/资源重载 `reset()` 走 `recordRenderCall`。
- **Geo 渲染器**：bloom 捕获标志在 finally 里还原；内层 PoseStack 显式复制调用者的 pose 与 normal（法线不丢）；平移 (0.5, 0.01, 0.5) + 成型朝向旋转与注释一致。
- **染色（MachinePartColors）**：逐方块注册而非 `Block.class` 全量（避免把别的模组方块卷进来——注释引用 Jade 教训）；无 tint 时返回 0xFFFFFF 中性。
