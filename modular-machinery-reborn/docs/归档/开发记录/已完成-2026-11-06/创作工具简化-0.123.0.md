# MMCER 0.123.0 创作工具简化（2026-11-06）

新增独立“配方编辑器”物品 `modular_machinery_reborn:recipe_editor`（创造栏可取），右键打开；对控制器使用会带入其机器。原 `/mm-recipe_editor` 保留。需要创造模式和命令权限 2，仍由服务端复核权限、会话票据、ID、资源与文件路径；协议 13，客户端／服务端一起更新。

## 最终范围

- 配方编辑器默认输入／输出材料格：点空格搜索（名称或 ID），JEI 拖入物品／流体／气体，滚轮 ±1、Shift 滚轮 ±10，右键删除、左键详情。时长填写秒数，按 20 tick/s 精确转换；FE/t 保留 long 精度。配方 ID 自动生成，高级模式仍可自定义。
- 原表单、概率、标签、NBT、原文、并行与 KubeJS 继续在高级编辑中使用。隐藏的高级字段保留；复杂能源条件单独编辑；输出范围不会被滚轮压成单一数量。JEI 材料只是虚拟输入，不消耗背包物品。
- 结构工具仅简化导出设置与预览，默认导出完整 JSON，可切高级设置和查看代码。机器身份建议保留手写 ID，换控制器时仅更新自动生成的身份；身份建议不取消待完成角点。
- **按用户最后指示，选块部分保持原样**：默认 SINGLE／TOGGLE，框选、逐块选择、增加／移除、空气处理、撤销恢复、控制器点击与潜行打开面板均沿用原行为。曾尝试的控制器角点快捷流程已撤回；原 ConstructToolItem／ConstructToolClient 源码与改前基线字节一致。
- 保存仍进入服务端 exports，需按预览中的 ID／路径安装，再手动重载；未实现自动部署或自动安装。关闭编辑器仍结束草稿会话，原文可先复制。
- **无线仓贴图仅保留设计稿，不接入游戏**，遵循用户明确选择。[设计稿与提示词](../../../开发/无线能源仓贴图生成说明-0.123.0.md)。16 个无线仓模型和原纹理未改。
