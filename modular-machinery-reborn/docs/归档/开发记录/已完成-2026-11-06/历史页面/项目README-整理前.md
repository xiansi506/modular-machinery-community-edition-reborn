## 使用前

- JAR 不内置机器和机器加工配方，请使用教程或仓库示例自行定义。
- 客户端与服务端同时更新；新增专属控制器需要重启，定义修改按教程重载。
- 可选联动需要对应模组及其依赖。源码推送与二进制 GitHub Release 是两个步骤，下载以实际 Release 为准。
