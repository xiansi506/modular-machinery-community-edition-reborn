# Modular Machinery: Community Edition Reborn

为 Minecraft 1.20.1 / Forge 打造的自定义多方块机械框架，基于 1.12.2 的 Modular Machinery: Community Edition 重新实现。你可以把自己设计的建筑变成加工设备，为它安排物品、流体、能源、气体、魔力、灵气、血魔法资源、压缩空气与余烬能量的输入输出，再用并行、工厂线程和升级系统扩展生产能力。

适合整合包作者、服务器管理者，以及希望自己设计生产流程的玩家。机器结构可由 JSON 数据包、配置文件或 KubeJS 脚本提供，加工配方使用数据包或 KubeJS；模组 JAR 不内置机器定义和机器加工配方，仓库另外提供可选示例。

## 可以做什么

- **设计机器**：任意形状、多层结构、方块状态和结构 NBT 条件、材料候选、变量集、部件选择标签和重复段动态结构；可使用通用控制器，或预先声明专属机器／工厂控制器。脚本可为结构部件增加方块检查器。
- **可视化创作**：`/mm-recipe_editor` 提供机器／需求表单、JEI 材料拖入、NBT 和原文编辑、校验、用量预览，以及 JSON／KubeJS 导出；结构工具可框选、撤销、替换材料并导出完整机器。
- **编写配方**：物品、流体、逐 tick 能源、Mekanism 气体、植物魔法魔力、自然灵气、血魔法 3 LP 与恶魔意志、气动压缩空气与压力条件、余烬小数能量、备选原料组、数值接口、概率消耗与产出、范围产出，以及提供本次合成增益的可选催化剂。
- **扩展生产**：并行控制器、内置并行、工厂独立配方线程、核心线程、升级总线、结构修改器与部件分组。
- **高级脚本**：机器／配方／升级专属回调、物品检查与改写、耐久和燃料需求、延迟触发、持久自定义数据、具名运行时修改器，以及工厂线程进度与配方列表控制；客户端可追加 GUI 信息，动态选择模型并控制动画序列与参数。
- **搭建和查看**：蓝图与 JEI 结构预览、逐层查看、可折叠预览按钮与可见方块状态、F3 绘制统计、世界幽灵投影、自动搭建，以及把已建结构导出成 JSON 片段的结构构造工具；JEI 支持气体贴图和自然灵气绿色条。
- **接入整合包**：KubeJS 机器／配方与生命周期事件；熔炉配方导入与机器间配方复用；可选 AE2 统一 ME 总线、**ME机械样板供应器**与**ME机械样板镜像**，支持物品、流体及通过 Applied Mekanistics 接入的气体；供应器具备 36 样板槽、物品／流体／气体持久缓冲、五种模式、按样板隔离、耗电退回、手动辅助输入和存储卡绑定的镜像；可选 FluxNetworks／龙之研究 long 能源、Jade 完整能量信息与 GeckoLib 全亮／透明／光晕模型。

机器由服务端加载并同步给客户端。数据修改通常可以 `/reload`；新增专属控制器等方块注册需要重启。KubeJS、JEI、Mekanism、AE2、Jade、GeckoLib、植物魔法、自然灵气、血魔法、气动工艺和余烬复刻版均按所需功能选装，相关依赖请同时满足各模组自己的要求。

新增资源联动见 [气动工艺与余烬](../../../../联动/气动工艺与余烬.md)。
