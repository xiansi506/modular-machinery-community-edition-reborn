# Modular Machinery: Community Edition Reborn

为 **Minecraft 1.20.1 / Forge / Java 17** 提供自定义多方块机械框架，移植自 Modular Machinery: Community Edition 1.12.2。当前源码 **0.123.1**，通信协议 **13**。

机器结构与加工配方由作者通过 JSON、配置文件或 KubeJS 定义；模组 JAR 不内置机器或机器加工配方。

## 下载与使用注意

- 二进制包以 [GitHub Releases](https://github.com/xiansi506/modular-machinery-community-edition-reborn/releases) 中实际发布的文件为准。当前 0.121.0 已推送源码，尚未创建对应二进制 Release。
- 客户端和服务端应使用相同版本；新增专属控制器需要重启，普通定义修改按教程重载。
- 两项创作工具只导出文件，需要手动安装定义。真实 GUI、拖拽与多人联机仍待实机验收；详见[注意事项](../../../../已知限制.md)。
