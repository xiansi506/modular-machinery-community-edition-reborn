# MMCER 无线能源仓 0.122.0（2026-11-05）

新增无线能源输入仓／输出仓，直接加入 Flux Networks。协议仍为 13；旧漏洞修复账本保持 122 完成／0 部分／0 待处理，这次为单独授权的新功能，不重开旧修复轮次。

## 使用

两族各八个等级。输入仓作为原生通量点，输出仓作为原生通量插头；右键使用 Flux 自带界面。详见[中文使用说明](../../../联动/能源与特殊渲染.md)与[English](../../../en/Energy-and-special-rendering.md)。合成是同等级普通能源仓加对应通量点／插头。结构定义要显式允许新方块。容量、速率复用普通能源仓的 long 配置，新增可染网络色的顶部无线标记。

## 实现与边界

- 使用真实 `TileFluxDevice` 子类及 `IFluxPoint`／`IFluxPlug`，兼容原生菜单、选网消息、权限、密码、优先级、超流与区块加载校验。不新增 MMCER 菜单或数据包，协议不变。
- 配方通过 `MachineInputProvider` 收集同一份 final `LongEnergyStorage`；保留 selector-tag 与输入输出方向。Flux handler 的 `mBuffer` 只是显示镜像，不形成第二份能源库存。Jade 使用相同的 long 视图协议，比较器和机器染色也已接入。
- 按网络 cycle 合计限速，用户限额／硬件速率取小值；旁路仍受硬件限制。极端配置按网络点数量分配请求安全上限，避免本功能多个请求合计溢出。外部 FE／OP 等接口仍按原来的每次调用限制；不宣称跨所有接口共享全局 tick 预算。
- 回合结束后的请求反映下一回合可接收量，避免原生通量插头从第二 tick 起被零 buffer limiter 饿死。统计正负号按 Flux 约定：插头为正、通量点为负。
- 首次入网尚在 native addition queue 时，拒绝立即换网，下一网络 tick 后可重试。拆除／卸载发生于首个分类周期之前时补发移除；无法从已卸载或被替换的实体传输。删除包含待加入设备的网络时，原生 API 会遗留指向已清空列表的私有 `mNetwork`；本联动仅在该墓碑状态通过一次延迟初始化的反射清除指针，再让 native API 正常管理后续绑定。此字段取自实际 7.2.1.15，需要后续升级 Flux 时复核。
- 保存网络 ID、owner、设置与能量。设置包不接受 owner／网络／缓冲覆盖。负能量、越界容量、负限额、过大优先级及缺 owner 的临时预览 NBT 均有处理。拆除只掉同等级空仓，放置后重新选网。
- 依赖缺席时不注册新块、物品、BE 或 loot。合成有 `forge:mod_loaded` 条件，挖掘标签引用为 optional。动态 loot 仅在依赖存在时生成，每个 size 掉对应等级物品。现有普通仓及其他 AI 未提交改动保留。
