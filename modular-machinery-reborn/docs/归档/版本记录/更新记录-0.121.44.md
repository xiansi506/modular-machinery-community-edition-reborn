# 更新记录 0.121.44（2026-11-03）

第六批 **K 组**，从 0.121.43 递增为 0.121.44，协议 **12** 不变。真实起点 0.121.43：340 份源码哈希与 class 快照均取自改前实态（未用 0.121.42 冒充）。**标待 Codex 验收。**

## 问题

- **K1 / P10-14**：JEI 在 `RecipeLayout#drawRecipe` 把 pose 平移到配方原点后调用槽位背景；文字随 pose 平移，`GuiGraphics.enableScissor` 不读 pose，仍用格子局部坐标。宿主平移 (120,70) 时文字与裁剪不在同一空间，缺贴图气体/魔力文本可能被裁到页面左上角之外。
- **K2 / P10-15**：`drawTextInCell` 在 `enableScissor` 与每行 `pushPose` 之后没有 `finally`。文字 sink 抛异常时 scissor 深度与 pose 栈都泄漏。

## 修复（MachineRecipeCategory.drawTextInCell + 私有 absoluteCellRect，仅此一份源码）

- 进入文字自身 `translate/scale` 前，用当前 pose 矩阵转换格子四角到绝对 GUI 坐标；左/上 `floor`、右/下 `ceil`（向外取整，覆盖非整数/负平移）。随后照常 `enableScissor`/`disableScissor`；不取消裁剪、不乘窗口 GUI 倍率、不改共享 3D `StructurePreviewRenderer.clip`。【Codex勘误】1.20.1原生scissor栈会与外层矩形求交，无交集为空，结束后恢复外层。真实CPU栈的交集/空交集/恢复已补验。
- 每行 `pushPose` 后内层 `finally` pop；scissor 用外层 `finally` 归还。不 catch 原异常；`enableScissor` 失败不 `disableScissor`，`pushPose` 失败不多 pop；不清空调用者栈。
- 未改共享 matcher/3D renderer/网络/协议/全局渲染状态。
