# MMCER 0.123.2 · ME 自动化修复

2026-11-07 · Minecraft 1.20.1 / Forge / Java 17 · 协议 13

- ME 输入总线拆除时仅掉落真实物品库存。配置格和滚轮目标量只用来设定标记。
- ME 流体配置保留容器中的 NBT。补充、超量退回和清除标记按完整流体身份计算，网络部分接收时保留余量。旧存档中的无标签标记仍可读取。
- 隔离模式有重复加工样板时，派单按槽位顺序使用第一个能接收整批的槽。
- 供应器拆下时，如果共用样板缓冲为空，掉落物保留合成锁模式但清除本轮锁定。共用缓冲还有材料时保留锁，普通区块存读档仍恢复原状态。

Java 17 离线 clean build 和 reobf 成功。27 项专项断言覆盖实际拆除调用、带 NBT 流体标记与存档、流体部分回网、重复样板派单和供应器拆放。物品标记与结构失效后解锁的回归通过。测试使用隔离世界、模拟 ME 网络和真实方块／菜单代码，真实 AE2 网格和合成 CPU 待实机验收。
