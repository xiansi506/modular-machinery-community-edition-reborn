# MMCER 0.124.0

2026-11-15 · Minecraft 1.20.1 / Forge / Java 17 · 协议 14

普通和工厂控制器在蓝图槽下方提供配方选择。可搜索当前机器的配方名称、产物或 ID。锁定限制新开工和工厂续单，已经开工的批次按原配方结算。选择保存在方块实体中，旧存档默认自动选择。目标被移除时会保持锁定，可恢复配方、换一个目标或切回自动。服务端校验菜单、距离、控制器身份、建造权限和已开启的所有者保护。[操作说明](../../使用说明.md#六并行工厂与配方锁定)

## 验证

- 普通与工厂控制器各通过 45 项离线断言。实测缺料等待、补料恢复、配方移除和恢复、工厂续单、切换时结算上一批、锁定的存档读取、旧存档自动模式、脚本否决以及菜单请求校验。
- 结构失效与工厂线程身份回归通过。离线夹具执行真实控制器和网络包处理方法，菜单请求经编码、解码和模拟服务端上下文派发。还需实机验证界面、真实区块存读和多人网络传输。
- Java 17 下 `clean build --offline --no-daemon -Puse_local_deps=true` 通过。归档 JAR 与 reobf 输出一致，共 1,818,601 字节。
