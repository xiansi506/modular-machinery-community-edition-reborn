## 简易导出

1. 按原来的方式选好方块，右键控制器打开导出设置。
2. 默认显示机器 ID、名称、格式和预览按钮；ID 会自动建议，已有绑定机器可带入其信息，手写 ID 不会被自动覆盖。默认导出完整 JSON。
3. 点击“下一步：预览机器”，确认选区和目标文件，再点“保存机器文件”。需要时点“查看代码”。
4. 仍将服务端 exports 中的文件安装到 machinery 目录或数据包，并按教程重载。

“高级设置”保留原有状态字段、匹配／预览 NBT、片段和 KubeJS 等导出能力。切换简易／高级不会丢弃已填写的设置。选区页保留原有全部控件。

# 结构构造工具

适用于 **0.123.0 / Minecraft 1.20.1 / Forge / Java 17**，协议 **13**。客户端与服务端同时更新。需要创造模式和命令权限 2。

## 开始操作

1. 手持建造选择工具，**潜行右键空气或方块**打开工具面板。
2. 在“选区与材料”页选择“逐块”或“两点框选”，以及“切换／增加／移除”。关闭面板返回世界后右键方块选择。
3. 框选时右键两个角点，范围包含边界；第一角点显示绿色轮廓。一次完成的框选算一步撤销。第一角点尚未完成时，“撤销”只取消角点。
4. 普通右键机器控制器，将其设为原点并打开“导出设置”。填写机器 ID、名称，设置字段和格式，点击“校验并预览”。
5. 查看目标文件名和分页内容，滚轮滚动当前页。“复制本页”只复制当前页；完整文件使用“确认导出”保存。

0.119.1 的“右键控制器立即导出”改为预览后确认。非创造模式或无权限时保留正常方块交互。

## 选区、撤销与材料

- 默认逐块切换，排除空气。增加模式保留已有选区，移除模式只取消指定位置；已选位置即使变成空气，也能取消。
- 面板提供撤销、恢复、清空。新的选区编辑会清除恢复分支；最多保留 32 步，历史总坐标数也受限，大选区的可恢复步数可能更少。
- 框选体积与最终选区均最多 **32768 格**。超限或经过未加载区块时整次操作失败，已有选区和第一角点保留。工具不会强制加载区块。
- HUD 显示数量、范围、模式和待完成角点。已选方块轮廓显示距离保持 32 格。
- 在原方块 ID 和替换描述符中填写如 `minecraft:stone` → `minecraft:iron_block`，添加导出材料替换；最多 16 项。只改变导出数据，世界建筑保持原状。替换规则按原方块 ID 匹配，替换后不继承源方块实体 NBT。
- 修改面板设置会取消尚未完成的第一角点。切维度、重生、断线或服务器停止会清理会话；设置和选区不跨重启保存。

## 状态与 NBT 筛选

“保留的方块状态”：`*` 保留全部，空值全部忽略，或填写 `facing,half` 等属性名。坐标和原生方块状态会一起归一化为控制器朝北，无需手工再旋转。

“匹配 NBT 字段”和“预览 NBT 字段”相互独立，默认均为空：

| 填写 | 含义 |
|---|---|
| 空 | 不导出这一类 NBT |
| `*` | 保留全部可导出的字段 |
| `Energy,Mode` | 保留这些顶层字段 |
| `/nested/tier,/ForgeCaps/example:cap` | 保留指定嵌套字段，逗号分隔 |

嵌套路径采用 JSON Pointer 的键转义：`~1` 表示 `/`，`~0` 表示 `~`；当前筛选沿复合标签查找，不支持列表下标。某个方块不存在的字段会忽略，请检查预览确认选中了所需内容。坐标不进入 NBT，机箱运行时染色不作为结构条件。

工具用字面快照保留数字类型、空容器、类型数组和字符串原文。库存、能量、进度等一旦选作匹配 NBT，就会成为成型条件，应只保留需要的稳定字段。手写的正则／范围模板继续按原规则解析。

## 格式与文件位置

所有文件写到服务器实例的 **`config/modular_machinery_reborn/exports/`**。文件名采用小写玩家名与时间戳，重名添加 `_1`、`_2`，不会覆盖旧文件。专用服务器上由管理员取回文件。

- **parts 片段**：把 parts 复制到自己的完整机器定义中。
- **完整 JSON**：包含机器 ID、名称、parts 和无需蓝图的默认设置。复制到数据包 `data/<namespace>/machinery/` 或配置的 machinery 目录，再 `/reload`。
- **KubeJS**：复制 `.js` 到 `kubejs/server_scripts/` 再 `/reload`；需要安装 KubeJS。导出脚本本身不要求安装 KubeJS，执行脚本时才需要。JSON 与 KubeJS 二选一安装，避免同 ID 覆盖。

完整定义通过实际机器解析器校验，生成的 KubeJS 使用现有 `.field("parts", ...)` API。新增专属控制器仍需配置预声明并重启；导出的结构不会自动获得加工配方。

确认保存时会复核选区、设置和世界内容。预览已失效、区块不可读、控制器超出 64 格或磁盘写入失败时保留选区；世界变化需重新预览。完整写入成功后才清空选区，仍可撤销恢复后再次导出。预览内容按每页 8000 个 UTF-16 代码单元分页，完整导出上限约 4M 代码单元。
