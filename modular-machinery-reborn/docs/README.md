## 使用者文档（本目录）

给玩家与整合包作者。**本模组不携带任何机器与配方**，内容分发方式为**仅文档引导**，所以这一组就是「内容的分发方式」。

| 文档 | 用途 | 什么时候读 |
|---|---|---|
| [`使用说明.md`](使用说明.md) | **入门主文档**：从空实例到一台能跑的机器与一份配方（三种机器来源、两种配方写法、控制器怎么选、构造工具、`/reload` 与重启、Hello World、排错表） | **第一次用这个模组** |
| [`已知限制.md`](已知限制.md) | **做不到什么、为什么**：刻意的设计决定、已知缺口、还没被人用眼睛看过的部分 | 遇到「为什么没有/为什么不行」 |
| [`KJS-配方指南.md`](KJS-配方指南.md) | **KubeJS 字段表**：配方与机器定义的完整字段、`.part`/`.parts` 的区别、合并优先级、排错 | 用 KubeJS 写机器或配方 |
