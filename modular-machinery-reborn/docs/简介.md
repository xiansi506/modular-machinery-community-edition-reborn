# MMCER 功能简介

**Modular Machinery: Community Edition Reborn · 0.123.1 · Minecraft 1.20.1 / Forge / Java 17 · 协议 13**

把自己设计的建筑变成加工设备，再用配方、仓口、并行和工厂线程建立生产流程。适合整合包作者、服务器维护者和希望设计机器的玩家。机器定义支持 JSON、配置目录与 KubeJS；模组不内置机器和机器加工配方。

## 已支持的主要能力

- **结构创作**：多层结构、方块状态和 NBT、材料候选、部件标签、动态段、专属控制器、工厂控制器。结构工具支持逐块和框选、撤销、筛选及完整 JSON／KubeJS 导出；选块操作未变。
- **可视化配方**：独立配方编辑器物品，右键打开。用输入／输出材料格、名称搜索、JEI 拖入和滚轮填写材料，用秒数和 FE/t 填写常用参数；高级表单、NBT、并行、原文与脚本导出保留。0.123.1 已为右侧 JEI 预留空间。
- **加工资源**：物品、流体、long 能源、Mekanism 气体、魔力、自然灵气、LP、恶魔意志、压缩空气和余烬能量；支持概率、输出范围、催化剂与修改器等高级配方。
- **生产与脚本**：并行、工厂独立线程和核心线程、升级总线、结构修改器、输入组、生命周期回调、持久脚本状态，以及客户端 GUI／模型／动画扩展。
- **网络自动化**：统一 ME 总线、**ME机械样板供应器（ME Machinery Pattern Provider）**、**ME机械样板镜像（ME Machinery Pattern Mirror Image）**。ME 气体需要 AE2、Mekanism 与 Applied Mekanistics。
- **能源与显示**：八级无线能源输入／输出仓直接加入 Flux Networks，原生选网与权限；龙之研究 OP／long 接口、Jade 能量信息、JEI 多方块预览、蓝图、幽灵投影，以及 GeckoLib 全亮／透明／光晕。

联动模组与依赖按需安装，完整清单见[主页](../../README.md)。第三方配方适配器、其他能源后端与其他魔法体系未随本轮增加；无线仓新贴图只保留设计稿。

## 使用与边界

创作工具要求创造模式和权限等级 2。导出文件需手动安装、重载；新增专属控制器等注册内容要重启。客户端与服务端同时更新，升级前备份世界并完成在途加工。

正式构建与所列离线专项通过，真实画面、JEI 操作、完整可选模组组合、存读档和多人联机仍需实机验收。旧版 CraftTweaker／ZenScript 脚本不能直接运行，迁移范围与资源事务支持契约见[注意事项与限制](已知限制.md)。
