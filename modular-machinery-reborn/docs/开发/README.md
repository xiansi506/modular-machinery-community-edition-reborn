使用 Java 17：`./gradlew clean build --offline --no-daemon -Puse_local_deps=true`。本地模式需准备 build.gradle 列出的依赖；默认 Maven 模式从对应官方仓库下载。`libs/` 依赖与构建 JAR 不提交到 Git。核对 reobf 和归档 SHA-256；Gradle test NO-SOURCE 不等于游戏测试。
