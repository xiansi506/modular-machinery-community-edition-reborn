## 结构构造工具增强

首版实现（0.120.0）：

- 增加两点框选和选区加减模式，提供排除空气的选项，并显示选中数量与范围。
- 支持撤销／恢复选区操作，以及按材料批量替换选区中的导出描述。
- 导出前选择保留哪些方块状态和 NBT 字段，区分结构匹配条件与预览显示数据。
- 填写机器 ID、显示名称等信息后，生成完整机器 JSON 或等价 KubeJS 定义；保留现有 parts 片段导出。
- 展示目标文件与内容预览，沿用失败保留选区、维度隔离和避免覆盖旧文件的规则。

验收重点：四个水平朝向、框选边界、添加／移除／撤销组合、空气过滤、状态／NBT 筛选；导出的完整定义能由实际机器解析器读取。专属控制器新增仍遵守启动注册与重启要求。多人权限、跨维度和区块不可读场景需要实际游戏验证。

## 可视化配方编辑器

首版实现（0.121.0），操作见[编辑器教程](../可视化配方编辑器.md)：

- 选择已定义机器，编辑配方 ID、加工时间、并行数，以及输入／输出需求。
- JEI 可用时支持拖入材料；同时提供按注册 ID 检索或填写的入口。
- 用表单编辑物品、流体、气体、能源及项目已经接入的魔法／压缩空气／余烬资源，明确数量、单位、一次性和逐 tick 的区别。
- 提供 NBT、标签、概率等常用参数，并预览配方展示和基础耗量；条件计算结果注明适用范围。
- 导出数据包 JSON 或 KubeJS 代码。复用现有解析规则进行格式和关联检查，提示缺失机器、依赖模组和明显的仓口配置问题。
- 对首版未覆盖的高级字段提供原文编辑入口，保留其内容，避免可视化编辑丢掉已有脚本配置。

验收重点：JSON 与 KubeJS 导出符合当前实际 API；同一份需求在编辑器、导出文件与 JEI 中的数量／单位一致；常用资源、NBT、标签和并行组合通过回归；实际拖拽、输入、保存和多人权限通过游戏验收。

## 实施边界

先完善结构工具，再实现配方编辑器，尽量共用校验与导出能力。开始实施时按新增功能规则递增版本，不把本计划条目记为已完成。

现有暂缓范围保持：不新增第三方配方适配器；其他魔法体系留空；跨模组能源范围保持 Flux Networks 和 Draconic Evolution。以上计划面向当前已经接入的资源体系。

## English

The structure-tool first version is implemented in **0.120.0**, with offline validation complete and gameplay acceptance pending. The visual recipe editor first version is implemented in **0.121.0**, with gameplay acceptance pending:

1. **Structure selection/export tool enhancements:** cuboid selection, add/remove modes, air filtering, selection undo/redo, counts and bounds, batch material substitution, block-state/NBT field selection, and complete machine JSON/KubeJS export.
2. **Visual recipe editor:** machine selection, JEI-assisted material input, forms for currently supported resources and common recipe parameters, clear units and per-tick semantics, preview, validation, and JSON/KubeJS export. Advanced fields must survive editing through a raw-text entry point.

Implement the structure tool first and reuse validation/export code for the recipe editor. Version 0.120.0 implements the structure tool; the visual recipe editor first version is implemented in 0.121.0. Existing integration scope and in-game acceptance requirements continue to apply.
