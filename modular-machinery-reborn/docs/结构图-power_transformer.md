# power_transformer 结构图

> 渲染自 `data/modular_machinery_reborn/machinery/power_transformer.json`（0.6.0）
> `registryname` = **`transformer`**（注意：文件名叫 `power_transformer.json`，但机器注册名是 `transformer`，配方里的 `machine` 字段要写 `transformer`）
> 尺寸 **3 × 5 × 3**，跨 Y −1..3 共 **5 层**，32 个部件 + 1 个控制器

## 方位约定

坐标是相对控制器的。**相对坐标 → 世界的方位，由控制器朝向决定**，但有一个恒定关系：

> **结构始终从控制器「背后」那一侧展开**，也就是控制器正面朝向的反方向。

下面的图按 **控制器 `facing=north`（正面朝北）** 画出。此时：

| 相对坐标 | 含义 |
|---|---|
| `x = −1 / 0 / +1` | 西 / 中 / 东 |
| `z = 0` | 北（**控制器所在的那一排**） |
| `z = 1` | 中间排 |
| `z = 2` | 南（结构末端） |
| `y = −1` | 控制器下方一层 |
| `y = 0` | **控制器所在层** |
| `y = 1..3` | 控制器上方三层 |

控制器正面朝北，而结构朝南（`+z`）伸展——即**在控制器背面那一侧**。把控制器转向别的方位，整张图会一起绕控制器旋转。

## 逐层视图

每层是 3 列 × 3 行：列 = x（西→东），行 = z（北→南，从上往下读）。`·` = 该位置**不需要**放方块（结构不检查这里，可以留空）。

### Y = −1（底座）

```
       西      中      东
z=0   石砖    石砖    石砖
z=1   石砖    石砖    石砖
z=2   石砖    石砖    石砖
```

一整片 3×3 石砖地板。控制器就坐在这一层 **z=0 中间那块的正上方**。

### Y = 0（控制器所在层）

```
       西      中      东
z=0   栏杆   控制器   栏杆
z=1   能源出  红石   能源入
z=2   栏杆    机箱    栏杆
```

- `控制` = **控制器本身**，不是结构的一部分（结构判定时会跳过原点）
- `能源出` = 能源输出仓（`energy_output_hatch`，任意等级都可）
- `能源入` = 能源输入仓（`energy_input_hatch`，任意等级都可）
- `机箱` = 任意机箱（`blockcasing`，6 种变体任选）

### Y = 1

```
       西      中      东
z=0    ·     栏杆      ·
z=1   栏杆    红石    栏杆
z=2    ·     栏杆      ·
```

十字形铁栏杆，中心是红石块。

### Y = 2

```
       西      中      东
z=0    ·     栏杆      ·
z=1   栏杆    红石    栏杆
z=2    ·     栏杆      ·
```

与 Y=1 完全相同。

### Y = 3（顶层）

```
       西      中      东
z=0    ·     栏杆      ·
z=1   栏杆    铁块    栏杆
z=2    ·     栏杆      ·
```

与 Y=1/Y=2 同形，但中心换成**铁块**。

## 立起来看（南北剖面，x = 0）

```
          z=0      z=1     z=2
y=3      栏杆     铁块     栏杆
y=2      栏杆     红石     栏杆
y=1      栏杆     红石     栏杆
y=0     控制器    红石     机箱
y=-1     石砖     石砖     石砖
```

即控制器正后方（z=1）立着一根柱子：红石 ×3 + 铁块顶；柱子两侧（z=0 与 z=2）是铁栏杆。

## 建造顺序建议

1. 先铺 Y=−1 的 3×3 石砖
2. 在石砖 z=0 中间那块**上方**放控制器；放置时**站在控制器位置的北侧、面朝南**，即可得到 `facing=north`，与上图完全一致
3. 同层按 Y=0 图摆好栏杆、红石、两个能源仓、机箱
4. 往上叠 Y=1、Y=2 的十字栏杆 + 中心红石
5. 顶层 Y=3 中心换成铁块

> 如果放控制器时朝向不对，不必拆——**整张图会跟着控制器的朝向旋转**，按「结构在控制器背面」这条规则建即可，或把控制器换成 `facing=north` 再对图。

## 几个容易踩的点

- **`transformer` 而不是 `power_transformer`**：文件名与机器注册名不一致，配方和 KubeJS 里必须用 `transformer`。
- **石砖是 `minecraft:stone_bricks`**：旧版写的是 `minecraft:stonebrick@0`，迁移时已换成 1.20.1 的方块名。
- **仓口与机箱不限定等级/变体**：定义里用的是「任意状态」匹配（旧版无 `@meta` 的语义），所以能源仓随便哪个等级、机箱随便哪种都算数。
- **`·` 的位置不能放实体方块吗？** 可以放，结构不检查那里，**放什么都行**（包括空着）。
- 结构判定每 10 tick 一次，所以拆/建之后最多约 0.5 秒才更新成型状态。
