## 二、修正前的问题

### A. 硬伤：物品名译错

| 键 | 修正前 | 旧版官方 |
|---|---|---|
| `itemmodularium` | **模块铀** | **模块化合金锭** |

「铀」是 uranium，与 Modularium（本模组核心合金材料）毫无关系；同一文件内 `jei...machine.title` 又写作「模块**化**机器」，文件内部亦自相矛盾。判定为「模块化合金锭」被截断/错字。

### B. 与旧版官方中文的系统性偏离

**等级用词 2 处不一致**（其余 7 个等级原本就一致）：

| 等级 | 修正前 | 旧版官方 |
|---|---|---|
| `normal` | 普通 | **中型** |
| `ludicrous` | 荒谬级 | **超级** |

**等级位置与格式不一致**：修正前 `物品输入仓（微型）`（类型在前 + 全角括号后缀），旧版 `微型物品输入仓`（等级在前）。影响全部 48 条等级键，会让老玩家按旧名搜索、以及 MC 百科词条对不上。

**「机器」/「机械」用词不统一**：`machine_controller` 修正前「机器控制器」，旧版「机械控制器」；`itemblueprint` 修正前「机器蓝图」，旧版「机械蓝图」。

**两个物品名丢失功能语义**：

| 键 | 修正前 | 旧版官方 |
|---|---|---|
| `itemconstructtool` | 构造工具（en: Construction Tool） | **建造选择工具**（en: Construct Selection Tool） |
| `machine_projector` | 机器投影器 | **机器结构投影仪** |

### C. 未汉化

`itemGroup.modular_machinery_reborn` 为纯英文 `Modular Machinery: Reborn`，是修正前唯一无中文的条目。旧版为「模块化机械 - 社区版」。

### en_us.json：对齐旧版官方英文（后补执行）

首轮仅修正了 1 处相对旧版官方的退化；随后按「英文格式与旧版对齐」要求，把全部等级键改为旧版官方英文。

| 类别 | 数量 | 变化 |
|---|---|---|
| 独立物品 | 1 | `itemconstructtool` → **Construct Selection Tool** |
| 等级仓口 | **48** | 后缀式 `Item Input Hatch Tiny` → 旧版前缀式 |
| 无等级仓口 | 4 | 与所属家族的等级命名保持一致 |
| 创造栏 | 1 | `Modular Machinery: Reborn` → **Modular Machinery Community Edition: Reborn** |
| 界面文案 | 1 | `no_recipe` → **No matching recipe found** |

英文等级命名最终形态（与旧版官方逐条一致）：

```
Tiny/Small/Normal/Reinforced/Big/Huge/Ultimate/Ludicrous + Item Input / Item Output
Tiny/Small/Normal/Reinforced/Big/Huge/Ludicrous/Vacuum   + Fluid Input Hatch / Fluid Output Hatch
Tiny/Small/Normal/Reinforced/Big/Huge/Ultimate/Ludicrous + Energy Input Hatch / Energy Output Hatch
```

> **一处需要知悉的旧版怪癖**：旧版对**物品**总线不写 "Hatch"（`Tiny Item Input`），只有流体与能源才写（`Tiny Fluid Input Hatch`）。本次严格照旧版镜像，因此物品仓口的英文名不带 Hatch。若希望英文统一带 Hatch，属于主动偏离旧版，需另行确认。

## 四、未改动项及原因

| 项 | 保持值 | 原因 |
|---|---|---|
| `redstonesignal` | 红石信号器 | 旧版无 Java 注册，**无官方中文名可对齐**；经确认沿用现名 |
| `wrench` | 扳手 | 同上 |
| 4 个无等级仓口 | 物品输入仓 / 物品输出仓 / 能源输入仓 / 流体输入仓 | 旧版无「无等级仓口」概念，类型词本身与官方一致 |
| `hatch.port` | 该仓口将在后续版本接入机器控制器 | 属占位说明文案，非命名问题；建议随**功能实现**一并替换，见遗留事项 |
| `machine_controller.completed` | 已完成（%s tick，%s FE） | 旧版同类文案（`tooltip.machinery.duration.tick`）亦未汉化 tick，保持与旧版一致的取舍 |
| `gui...formed` | 结构已形成 / `Structure formed` | 旧版仅有 `结构不完整`（missing_structure），无对应「已完成」文案，现译法合理 |
| `itemGroup` 英文 | `Modular Machinery Community Edition: Reborn` | 旧版为 `Modular Machinery Community Edition`。本项目名称本身多出 `Reborn`，故保留后缀；已补回 `Community Edition` 以与中文侧「社区版」对应 |

## 七、遗留事项

1. **`item_input_hatch_ultimate` / `item_output_hatch_ultimate` 的存废**：这两个等级是 Reborn 自创、旧版物品仓口不存在，且无对应贴图。若按 `移植方案-v2.md` 的 D1 决策撤销该等级，需同步删除这两条语言键。
2. **物品仓口英文名不带 "Hatch"**：这是严格镜像旧版官方英文的结果（旧版物品总线叫 `Tiny Item Input`）。若希望英文统一带 Hatch（`Tiny Item Input Hatch`），属于主动偏离旧版，需确认后再改，涉及 16 条键。
3. **`hatch.port` 占位提示**：该文案会作为 tooltip 出现在玩家界面，等于把开发状态暴露给玩家，建议随仓口能力实现一并移除。
4. **版本号与发布归档未同步**：按 `注意事项.md`，修改模组后须递增版本号（0.4.3 → 0.4.4）。本次已完成构建与语言修正，但 `gradle.properties` 版本、`迁移日志.md`、README 与 `releases/modular-machinery-reborn/v0.4.4/` 归档**尚未执行**；当前产出的 JAR 仍名为 `modular_machinery_reborn-0.4.3.jar`。需确认后补做。
