# 0.112.0 — 预览 NBT 方块实体

蓝图与 JEI 结构预览按 `preview-nbt`／`.previewNBT()` 创建独立方块实体，加载箱子、旗帜、告示牌等数据，并调用实体渲染器及 ModelData。预览使用隔离场景，不注册逻辑 tick；层切换和候选轮换重建实体，缓存有上限并在资源重载／断线时清理。

支持具体 NBT 的字面字符串、JSON 文本组件、数字／布尔、空列表；匹配 NBT 的正则与比较规则继续保留。实体类型／坐标由候选方块决定，预览不执行逻辑 tick。实体渲染异常会停用该实体绘制，回退普通方块显示。

预览 NBT 专项 27、完整套件 2669、高级脚本 57、既有专项 159 项均零失败；44 项可选依赖类加载通过。build/reobf 30s，177 JSON、中英各 401 键、SRG 与协议 5 检查通过。协议仍 **5**；与 0.111.0 相同，升级包本体时两端保持一致。
